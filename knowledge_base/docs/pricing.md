# Pricing

Pricing depends on project scope. The tiers below are starting
reference points for common project types; final quotes are provided
after a scoping call.

## Starter automation

For a single automated workflow (e.g. one support channel, basic intent
classification, no custom dashboard).
Starting at $800 (one-time), plus optional monthly monitoring at $100/mo.

## Standard support automation

Full pipeline: multi-intent classification, RAG-based knowledge
retrieval, confidence-based escalation, ticket management dashboard.
Starting at $2,500 (one-time), plus optional monthly monitoring at
$250/mo.

## Custom / enterprise automation

Multi-agent systems, custom integrations with existing CRM/helpdesk
tools, advanced analytics, SLA monitoring.
Custom quote based on scoping call.

## What affects price

- Number of input channels (web form, email, WhatsApp, etc.)
- Size and complexity of the knowledge base
- Number of required integrations
- Whether a custom dashboard or existing tool integration is needed
- Ongoing monitoring/maintenance requirements

## Payment terms

50% deposit to begin work, 50% on delivery, unless otherwise agreed in
writing. We do not process refund or payment changes automatically —
these always go through a human team member.
